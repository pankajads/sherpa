# Code of Conduct

Sherpa adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, assume good intent, critique ideas rather than people, and keep discussions welcoming to contributors of every background and experience level. Practitioners disagreeing about how M&A integrations should be run is healthy; personal attacks, harassment and discrimination are not.

## Confidentiality

Many participants work on real acquisitions. **Never post or ask for confidential deal information** (company names under NDA, deal timelines, unreleased plans) in issues, discussions or pull requests. Using such information in this project is a code-of-conduct violation.

## Reporting

Report code-of-conduct concerns privately to the maintainer via [GitHub](https://github.com/pankajads). Reports are handled confidentially, following the Contributor Covenant's enforcement guidelines.
